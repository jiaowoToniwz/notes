# 快速笔记（Quick Notes）

基于 AutoHotkey v2 的系统级轻量笔记工具：在任何程序中按快捷键即可记录信息，数据保存在本地纯文本文件中，可搜索、可编辑、可同步。

## 功能一览

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Alt+N` | 弹出黄色便签窗口，快速记录一条笔记 |
| `Ctrl+Alt+M` | 打开笔记列表主页面（搜索 / 查看 / 新增 / 编辑 / 删除） |
| `Ctrl+Alt+C` | 收藏当前程序中的选中文字（自动记录来源程序） |

- 托盘菜单：笔记列表 / 打开笔记 / 打开目录 / 设置 / 退出
- 托盘 → 设置：修改三个全局热键（立即生效并保存），以及**笔记存放路径**（可输入或浏览选择，保存时可选复制旧笔记）
- 常驻内存约 10~15 MB
- 数据为 UTF-8 纯文本（notes.md），记事本 / VS Code / WPS 均可直接打开
- 无数据库、无第三方依赖，拷贝整个目录即完成迁移

## 下载编译版（免安装，推荐）

不需要安装任何东西，下载 `notes.exe` 双击即可使用：

- **下载地址**：https://github.com/jiaowoToniwz/notes/releases （点最新版本的 `notes.exe`）
- 首次运行自动在 exe 旁边创建 `notes.md`（笔记数据）和 `notes.ini`（配置）
- 数据文件跟随 exe 所在目录，整个文件夹拷走即完成迁移
- **升级**：下载新版 exe 替换旧文件即可，笔记数据不会丢失

> 想自己改代码 / 手动编译的，看下文「编译为 exe」；想用脚本版直接跑的，看「安装教程」。

## 安装教程

### 1. 安装 AutoHotkey v2

方法一（命令行）：

```
winget install AutoHotkey.AutoHotkey
```

方法二：到 https://www.autohotkey.com 下载 **v2** 版本安装。

> 注意：必须是 v2，v1 无法运行本脚本。
> 不想装 AutoHotkey 也可以：把脚本编译成 exe，见下文「编译为 exe（免安装版）」。

### 2. 放置文件

将本目录（或其中以下文件）放到目标机器任意位置，例如 `D:\Notes`：

- `notes.ahk` — 主脚本
- `notes.md` — 笔记数据（可选，不存在时脚本会自动创建）
- `README.md` — 本文档（可选）

> **可移植**：笔记目录默认 = 脚本/exe 所在目录（`A_ScriptDir`）。整个文件夹拷到任何位置、任何机器都能用，无需改任何配置；也可在「设置」里把笔记改存到任意路径（如 D:\Documents\MyNotes），配置文件 notes.ini 仍随程序。

### 3. 运行

双击 `notes.ahk`（或右键 → Run Script），任务栏托盘出现图标即运行成功。

### 4. 设置开机自启

1. 按 `Win+R` 输入 `shell:startup` 回车，打开启动文件夹
2. 新建快捷方式：
   - 目标：`"C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" "D:\Notes\notes.ahk"`
   - 按实际 AHK 安装路径和脚本路径修改

### 5. 验证

- 按 `Ctrl+Alt+N` 存一条笔记，再按 `Ctrl+Alt+M` 确认列表中出现该笔记
- 重启电脑后确认脚本自动运行

## 编译为 exe（免安装版）

编译后得到独立的 `notes.exe`，目标机器**无需安装 AutoHotkey**，双击即用。

### 1. 获取 Ahk2Exe（只需一次）

1. 到 https://github.com/AutoHotkey/Ahk2Exe/releases 下载最新 `Ahk2Exe*.zip`
2. 解压出 `Ahk2Exe.exe`，放入 `C:\Program Files\AutoHotkey\v2\Compiler\`（或任意目录）

### 2. 编译

```
"C:\Program Files\AutoHotkey\v2\Compiler\Ahk2Exe.exe" /in "D:\Notes\notes.ahk" /out "D:\Notes\notes.exe" /base "C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" /compress 1
```

| 参数 | 说明 |
|---|---|
| `/in` | 源脚本路径 |
| `/out` | 输出 exe 路径 |
| `/base` | 基础运行时，v2 脚本用 AutoHotkey64.exe |
| `/compress 1` | 压缩输出（体积更小） |

编译成功后生成 `notes.exe`（约 1.2MB），功能与脚本版完全一致，常驻内存约 12MB。

> **Ahk2Exe 异常时的备用编译**：本目录自带的 `compile_exe.ps1` 用资源注入方式编译（复制 AutoHotkey64.exe 后把脚本写入其 RT_RCDATA 资源）。用法：`powershell -ExecutionPolicy Bypass -File D:\Notes\compile_exe.ps1`。注意编译前先退出运行中的 notes.exe（会锁文件）。

### 3. 部署

- 只需拷贝 `notes.exe`（数据文件 notes.md / notes.ini 不存在会自动创建在 exe 旁）
- 开机自启快捷方式的目标直接指向 `notes.exe` 即可
- 注意：**修改脚本后必须重新编译**，exe 不会自动同步改动

## 使用方法

### 快速笔记（Ctrl+Alt+N）

- 输入内容 → 按 `Ctrl+Enter` 或点「保存」即存入 notes.md
- 按 `Esc` 或点「取消」放弃输入并隐藏窗口
- 窗口是复用的：再按快捷键会重新显示（内容已清空）

### 笔记列表（Ctrl+Alt+M）

- **搜索**：搜索框输入关键词，实时过滤（同时匹配时间和内容）
- **查看**：双击某行，或选中后点「查看」；详情窗口可编辑内容，点「保存修改」写回
- **删除**：选中后点「删除」，有确认提示
- **新增**：直接弹出快速笔记窗口
- **刷新**：重新读取 notes.md（用别的软件手动编辑后可刷新）
- 窗口关闭只是隐藏，再按 `Ctrl+Alt+M` 恢复

### 收藏选中文字（Ctrl+Alt+C）

在任何程序中选中一段文字，按 `Ctrl+Alt+C`，自动保存并附带来源程序：

```
> 选中的内容

— 来自：Chrome
```

### 修改快捷键 / 笔记路径（托盘 → 设置）

- 三个热键输入框：点击后直接按组合键录入（须含 Ctrl/Alt/Shift，Esc 清空），保存后立即生效，重启不丢
- 「笔记路径」：输入或点「浏览…」选择目录；浏览对话框会**默认定位到当前笔记目录**，左侧导航可跳到任意位置，选定后路径自动填入；保存后笔记改存到新位置；若旧位置有笔记且新位置为空，会询问是否把旧笔记复制过去
- 「恢复默认」：热键恢复 Ctrl+Alt+N/M/C，路径恢复为程序所在目录

**什么时候建议设置笔记路径？**

- 想多机同步：把路径指向坚果云 / OneDrive 等同步文件夹，笔记自动多端同步
- 想单独管理：笔记与程序分开存放，如 `D:\Documents\MyNotes`
- 程序目录不可写（如装在 Program Files）

**默认行为（无需设置）**：不设置时笔记就在 exe 旁边，整个文件夹拷走即带走笔记。即使曾经设置过自定义路径，只要该路径等于程序所在目录、或已被删除（目录失效 / 换机器），程序启动时会自动清除该配置并回到 exe 旁——不会出现"笔记写回旧位置"的问题，无需手动改 notes.ini。

## 数据格式

`notes.md` 内容示例：

```markdown
# 快速笔记

## 2026-08-28 16:12
这是一条笔记内容

## 2026-08-28 16:13
> 收藏的引用

— 来自：Chrome
```

- 每条笔记以 `## yyyy-MM-dd HH:mm` 开头
- 可用记事本等任意编辑器直接修改；程序操作时会整体重写该文件
- 手动编辑时请保持 `## 时间` 的格式，否则列表解析可能异常

## 迁移与多机同步

- **迁移**：拷贝整个目录到新机器，重新安装 AutoHotkey v2，重建开机自启快捷方式（快捷方式不能直接拷贝）；或用编译版，只拷 `notes.exe` 即可（notes.md / notes.ini 不存在会自动创建在 exe 旁）
- **同步**：把目录放进坚果云 / OneDrive 等同步文件夹，多台机器笔记自动同步；若设置了自定义笔记路径，把该目录也放入同步文件夹
- 目录位置变化**无需任何修改**：笔记目录默认跟随脚本/exe（`A_ScriptDir`）；自定义路径记录在程序旁的 notes.ini 里（`[Settings] dir=`），若该路径等于程序目录或已失效（被删 / 换机器），启动时自动清除并回退 exe 所在目录

## 常见问题

### 热键与其他软件冲突

托盘右键 → **设置**，在窗口中直接改快捷键（立即生效并保存到 notes.ini，重启不丢）。

### 脚本没反应

- 确认托盘有脚本图标；没有则双击 notes.ahk 手动运行
- 托盘右键 → Reload 重新加载
- 检查杀毒软件是否拦截

### 修改脚本后不生效

改完必须重新加载：托盘右键 → Reload，或退出后重新运行。

### 打开文件乱码

所有文件均为 UTF-8 编码。若旧版记事本显示乱码，请用 VS Code / Notepad++ / WPS 打开。
